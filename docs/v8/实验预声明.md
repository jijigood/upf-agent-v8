# v8 原型实验预声明

完整矩阵在留出取用前写入各批 `freeze.json`。独立全量评估器与局部评估器共享确定性判定规则，但全量评估器独立遍历全部需求和动作，不读取局部依赖索引。实验只验证当前规则原型的正确性、来源可追溯性与代价。

| 规模 | 逻辑字段 | 状态 | 动作 |
|---|---:|---:|---:|
| S | 100 | 30 | 10 |
| M | 500 | 150 | 30 |
| L | 2,000 | 600 | 100 |
| XL | 10,000 | 3,000 | 500 |

每档更新 1/5/10/50 字段，每组种子 0–19，每种子 50 批，共 16,000 批。最终核验使用四个独立 CPU 工作进程、各自来源目录，组内全量/局部顺序计时；性能包含并发资源竞争，不能冒充独占单请求延迟。每批保存选中字段、实际值、revision 和更新回执。记录热运行 p50/p95、冷启动 p50/p95、重算数、一致性及模型/工具次数。不预设加速比例。旧开发核版本的完整矩阵单独保留在 `experiments/v8/local`。

图检索使用四个实际 P3 查询，同一批模型向量与八个检索种子，返回上限统一 100 节点：当前 Hybrid、固定两跳图扩展、契约约束扩展。每个图快照注入独立来源标识的“必需合法事实”与错版本/未知版本/过期/不可信/越界对象/无佐证关系六种控制。覆盖和精确率是合成适用性标签，不是人工语义相关性。普通 `HybridCypherRetriever` 在独立环境与真实 Neo4j 向量/全文索引上运行，使用同一批已校验的 1,061 向量；其种子底座与 P3 不同，单列结果，不并入同种子结论。

Agent 比较 B0–B4/Ours：B0 手册资料；B1 保留 P5 LangGraph 与冻结工具包；B2 契约；B3 契约和局部更新；B4 普通图上下文；Ours 完整流程和 Gate。模型为相同 baseline、相同配置/权重，最大工具/模型/轮次/时间为 8/8/3/180 秒。每个方法不必耗满预算；统计实际次数。B0/B2/B3/B4 是明确声明的模块消融，共享冻结资料预处理，其“工具次数”为声明的来源访问数；B1 与 Ours 为实际 backend/ledger 计数，不能混淆。Ours 决策头与其他方法使用相同本地模型，最终判定由 Gate；同次模型原始建议用于离线 GateOff 对照，不执行任何动作。

开发场景为两对象 N4、一个域边界；留出为四对象 N3、两个域边界、重复管理域，并加入复合故障。开发和留出来源组及结构组不同。oracle 在生成器中预声明合法/阻断动作集合，不调用评估器生成标签。所有场景标记 synthetic=true/reviewed=false；已有题库仅作开发回归。留出不用于调参，批次取用前落“已消费”标记；失败输出保留，后续新验收必须使用真正新的来源与结构组。

硬门槛：全量/局部语义完全一致、证据来源 SHA/locator/回执链完整、Ours 错误放行 0、合法正例正常建议、Memory/Neo4j 同语义、现有回归通过。空建议不能靠安全零错误拿通过：独立 oracle 中的所有合法动作也需被接受。缺边、非收敛环、预算、Neo4j 不可用和崩溃恢复由开发测试注入，失败结果必须阻断。模型原始回包、各方法 JSON/CSV、完整 freeze 与未通过历史产物均保存。
