LangGraph 复用流程、SQLite checkpoint 和中断；[官方持久化说明](https://docs.langchain.com/oss/python/langgraph/persistence) 与 [中断说明](https://docs.langchain.com/oss/python/langgraph/interrupts) 支持恢复机制。幂等账本、预算和状态采信由本项目实现。

NetworkX 使用 DiGraph、可达集、直接后继与环检测，图算法调用来自运行库；字段读取语义、依据比较与安全复用由本项目定义。[3.6.1 版本资料](https://pypi.org/project/networkx/3.6.1/)。

Neo4j 服务器固定 5.26.31-community，镜像 digest 已记录；主应用 Driver 6.4.0，普通 GraphRAG 1.22.0 使用独立 `.venv-graphrag`。调用官方 HybridCypherRetriever 和索引接口，没有复制上游检索实现。[官方检索说明](https://neo4j.com/docs/neo4j-graphrag-python/current/user_guide_rag.html)。

Graphiti 仅参考事实有效时间、Episode/来源关联；OpenSPG/KAG 仅参考 LFPlan 的计划与执行分层。我们的契约、冲突规则和 GraphQueryPlan 是确定性实现。Open5GS/UERANSIM/测量平台仅作为后续真实取证设计参考。

新增 orjson 3.12.0 用于稳定 JSON 与大批量实验序列化，其分组件许可 `MPL-2.0 AND (Apache-2.0 OR MIT)` 在已安装分发元数据中记录，全文保留在 `licenses/orjson/`。实际交付、分发数据库或权重时按对应项目许可处理；本轮未改写、复制上述第三方运行库源码。
