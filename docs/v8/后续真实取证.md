# 后续实际 Open5GS / UERANSIM 取证

本轮未部署实际测量平台。下阶段先固定 Open5GS、UERANSIM、配置和网络拓扑版本，记录环境镜像/commit/许可证、时钟同步状态、业务承载与管理域映射；每个用例必须有独立业务 ID 与对象别名表。

现有取证接入口是 `read_observation` 的受限文件能力。真实采集器在独立来源文件中写入 `source_id`、synthetic=false、有佐证的 `path`、角色、K/R/P 分类、实际字段、明确时区观察窗和配置/映射版本。N4 对 UPF/SMF 两侧记录 PFCP 关联、会话或心跳；N3 对 UPF/gNB 两侧记录 GTP-U 标识、端点、方向和接口实际状态。缺一侧、不同步或未知版本必须产生缺口，不能用 LLM 输出补全。

采集适配器还需固定查询对象/域/字段权限、原始文件 SHA、locator、采集工具版本和幂等键，通过本轮同一组契约与门控测试后，再进行真实故障注入和人工语义复核。真实标签 reviewed=true 需要保存实际人工复核回执。受控执行、现网部署和跨主机离线模型交付另行设计授权与回滚，不属于本轮可建议状态。

上游参考 commit、文件与许可见 `opensource-references.json`；Open5GS 的 PFCP 状态机和 UERANSIM 仅作为实际接口研究参考，测量平台若无明确授权，本轮不复制其代码。


2026-10-10 进度补充：现已完成实际隔离 Open5GS/UERANSIM 部署及 18 轮注入／清理／只读日志接入工程 pilot。固定版本、原失败和真实原始材料见 [E7 实际网络报告](e7-lab-report.md)。根因排名、双侧遥测的完整诊断评价与 60 轮扩展尚未完成；上文“本轮未部署”是最初交付时的历史状态。
