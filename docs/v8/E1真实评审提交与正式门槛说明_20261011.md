## 需要谁做什么

两名真实领域评审分别审核参考和原始方案。审核对象包括实验故障事实与正常观测是否一致、对象和产品版本、适用手册、必要步骤和依赖、允许的替代路径、证据冲突、缺证出口、禁止或无依据的建议。评审不只看动作名或 Schema。分歧保留原记录；需要改参考时另版冻结和重审，需要裁决方案时提供真实第三评审记录。

先看 `validation-inputs-005/organizer-only/<case_id>/review-instructions.json`，核对同目录的草稿及独立实验验证，并与模型可见的 `validation-inputs-005/cases/<case_id>/data/raw/` 对照。草稿 `solvability=solvable` 只是未批准的作者提案，允许评审改判。私有注入操作不能作为正常模型输入。UPF 空日志也不能被解释成已证实正常。

然后使用 `four-methods-003-audit/reviewer/` 中的材料。该包包含 48 份去显式方法标识的方案阅览件、12 份冻结可见输入、12 套编制材料和 96 行输出双席空表；参考另有 24 行双席空表。阅览件可按组织者密钥逆替换恢复原文，样式仍可能泄漏方法，不能声称完全盲审。实际评审原文 hash 绑定原始模型输出，不绑定阅览件替换后的 hash。

## 提交格式

参考批准使用已有 `upf_agent.v8.plan_review.GoldReview` 的 JSON 格式：每条记录包括 case_id、reviewer、reference_sha256、decision（approve 或 request_changes）、notes、review_version、review_source。reference_sha256 使用 `digest(CaseGold)` 的规范化 hash，不能用文件字节 hash 替代。review_source 必须是评审材料根目录内的相对物理文件；保留评审原始记录和文件 SHA。两名评审身份应为实际不同人员，且不能只靠大小写或空格伪造差异。审核脚本只能核对记录结构和 hash，专家资格与独立性仍需实际确认。

原始方案语义审核使用已有 `upf_agent.v8.e1_output_review.OutputReview`：case_id、method、raw_plan_sha256、reference_sha256、reviewer、role（reviewer 或 adjudicator）、semantic_valid（实际布尔）、review_version、review_source、notes。输出空表另有技术正确、安全和未知出口字段供专家说明，不能把它们默认填 true。正式版本必须审核该正式批次的原文，不能沿用本次工程输出的审批。

没有记录时保持空白；程序不会从草稿和机器评分产生 approve。引用、输入或参考变化后旧审批无效，不将未经核验的 CSV 直接覆盖 dataset。

## 从校准材料到正式 E1

本批是 validation 候选接口的工程校准，不是已经冻结的正式验证。它的 12 份参考草稿位于候选包内，原 60 例仍缺 36 份已批准的新领域参考，原 120 个 Gold 双评席位仍无真实提交。不能把当前 24 个草稿评审席位与原 120 席位相加后声称补齐。

采用本接口时，正式数据版本需明确登记任务、公开来源、对象权限和参考变化，经过审核再生成正式目录；原 24 份 heldout 仍封存。本轮仅对 validation 新采集，不能将其正常抓包或知识适用性直接拼接到历史 heldout。若 heldout 也采用新领域接口，应先按确定的正式采集协议准备同条件正常证据，建立和审核该版本参考，再冻结；没有资料的任务应保留未知出口或按协议登记不支持，不能删掉失败分母。此步骤尚未执行，避免在未确定协议及真实审核前读取或使用 heldout 答案。

正式入口 `scripts/v8_e1_formal.py` 已显式支持 `--runner-profile verified-runtime-candidate-1`，默认 legacy。新 profile 绑定真实来源核验、候选生成器、Translator 和完整 Validator，未绕过 Gold 双评、版本／来源隔离、正式 validation 原文审核或 heldout 防重复消费门槛。候选 profile 的名称不表示协议已经批准。

正确顺序为：按已收到的专家意见修订接口和参考 → 修订版本的参考批准及来源适用性确认 → 同版正式数据与协议冻结 → 正式 validation 四方法运行 → 该批原文双评／必要裁决 → heldout 版本冻结及单次运行 → heldout 原文审核和来源组件统计。当前缺修订版本批准与实际逐人双评登记，正式 gate 继续拒绝启动，VPR 保持 null。
