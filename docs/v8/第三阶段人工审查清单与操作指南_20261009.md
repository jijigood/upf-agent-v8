# 第三阶段人工审查清单与操作指南

自动实验的原文、来源、执行和成本复算由脚本完成。正式参考、自然语言方案语义和语义保持扰动，需要真实独立评审。

从[审查包填写指导](../../runtime/v8-next/phase3/independent-review-package-001/复核入口与填写指南.md)进入；该目录准备了公开输入索引及每项两份空白 CSV，不含伪造签名。

| 工作 | 数量 | 输入入口 | 核验重点 |
|---|---:|---|---|
| E2 查询参考 | 96 | `E2-public-inputs.json` | 从需求与原始资料判定相关且适用证据、等价集合和无证据条件；开发映射未审 |
| E3 发布参考 | 32 | `E3-public-inputs.json` | 每轮新证据是否有来源、版本、已知时区与权限；目标缺口和全任务状态分别核验 |
| E5 完整候选 | 120 | `E5-public-inputs.json` | 动作、参数、KRP、双侧映射、依赖、未知出口、执行或完成措辞 |
| E6 语义扰动 | 80 | `E6-public-inputs.json` | 原/扰动的目标、对象、版本、as_of、权限、方向、事实保持；机械相等不足以批准语言语义 |

操作顺序：读公开输入与物理来源 → 自行写 reviewer CSV → 对比开发参考 → 分歧保留原记录并仲裁 → 需要修订则新版本留档 → 冻结批准后的正式实验协议并复算。目录命名或 batch_id 仍可能透露开发类别，正式盲评前应由协调人隔离对照和准备呈现副本；该包本身不是已完成盲评的证明。

第二阶段已有用户单人审核保持原登记。20 个映射参考修订的确认继续使用[原修订确认清单](../../runtime/v8-next/phase2/reference-revision-review-package-001/修订参考确认清单.md)，第二位评审与必要仲裁保持未完成。第三阶段模板没有替代或覆盖原工作区。

填写指南列明每个实验的具体判定值、路径与停止条件。复核结束后，应根据真实记录更新[plan.md](../../plan.md)，而不是仅凭机器结果勾选人工项。
