## 安全、预算和成本口径

- 需求必须来自当前契约，契约必须与 Task 指纹一致；对象／字段权限和 domain 检查失败时返回 denied，不扫描证据。修改已编译 scope/as_of/fields 会被拒绝。
- 节点及关系都保留逻辑来源；校验物理文件 SHA、声明的佐证状态、对象、版本、有效期与知识映射。DocumentBlock／Command 只有在当前 registry 对来源 hash／locator／文段 hash／对象／目的的映射可用时才是 K 候选。
- BFS 与 PPR 使用相同输入图、种子、过滤、源节点／邻接扫描预算。PPR 不重新访问来源；返回 top-K 仅支持 5/10/20，alpha=0.85、容差 1e-8、最多 1,000 次迭代。本轮不调参；不收敛明确返回 not_converged，不发布部分排名。
- reseed 仅在未取得可用候选时尝试调用方预先提供的缓存 ID；同一剩余预算、最多 2 跳，不全图搜索，不借助预期答案补造 seed。
- 单图派发所有 K Requirement 的 **发现＋回写复核合计**不超过 100 次节点查找、200 次邻接项检查。每条查询先留出一半剩余预算给必要复核，失败／重复邻接检查也计数；另记来源 hash 读取、字节量、PPR 迭代及排名边访问、复核成本和图物化 setup。
- 这个扫描上限是**预加载 Memory 快照内的有界查找／邻接检查**。快照物化可能读取更多节点，单列 setup；不是数据库／磁盘只读 100 个节点的物理 I/O 保证。WP08 只支持 Memory 快照；现有 Neo4j 默认流程保留，不声称新查询后端已对齐。
- 回写以受信原始 store 再检索复核，不信任结果里重建的路径；scope、registry、来源、候选图、路径或内容改变时拒绝。只回写 K；R/P 返回授权投影的检索线索，配对采信／方案改善尚未实现。
- 图连接是有来源的逻辑关系，不证明物理业务拓扑；本模块没有替代业务路径、独立 Validator 或执行授权。所有动作仍只读。

## 保留的失败与修复

前三个控制包 `wp08-pilot-001/002/003` 原样保留。001 的项目根保护及复核计数后来补强，对应旧模块是事后按原 SHA 验证恢复，明确标为 reconstruction，不冒充运行前冻结。002/003 对应真实代码冻结均保留。

修后只保留节点来源明确声明的 observed 元数据；真实手册没有声明时仍为 None，没有造窗、移除时间比较或放宽 Validator。引擎探针同时要求实际回写、completed、所有状态 satisfied 和执行授权 false，另批 002 的三次全部通过。

另补图快照指纹：启用新策略时固定手册快照，扩展任务图使用其副本；改策略／缓存／快照后不能复用原运行的恢复指纹或回执，源手册图不被任务图污染。
