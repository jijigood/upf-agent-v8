64,000 方法批次单 worker 全量任务已完成并复核（2026-10-09）：四方法各 16,000 批一致，原始 CSV 成本复算通过。完整矩阵、负收益与分项成本见[全量复核报告](第三阶段E4全量复核与验收_20261009.md)。下文小矩阵与压力计时作为历史开发证据保留。以下速度比为同组四模式共用序列的更新总耗时比，不跨规模、冷热或 worker 相除。比值小于 1 即实际负收益。

## 计时口径

逐方法 update 的 wall/CPU 时间；随机方法顺序。输入生成、完整结果序列化、参考比较和持久化在计时外。初始化单独记录 index、fingerprint、初始规则和读集认证；这不是清空 OS 缓存后的磁盘冷读。L3 的逐读成员审计与三种 Local 共有的索引完整性审计分项保存。fallback 是重算时间子集，不能重复加总。

所有进程运行在共享机器；压力批次前段与本项目回归并行，稳定输出对照末段与压力任务并行，其时延仅为诊断值。RSS 是进程累计峰值，四模式共进程，不能解释为某个方法的独立内存。4-worker 吞吐尚未运行，不能以其结果冒充单请求延迟。
