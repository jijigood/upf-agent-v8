# 专利 S1–S6 对应表

依据归档 `docs/v8-preparation/专利v8.pdf`、逐页文本和输入 v2 规划。这里映射工程实现，不对专利法律有效性作判断。

| 专利步骤 | 本地实现 | 验证 |
|---|---|---|
| S1 解析任务与业务路径、识别实际管理域边界 | `OrchestrationTask` / `BusinessPath`；`verify_path`；`compile_contract`；静态域/承载构图；有序 `path_vector` | 四模板、路径候选、来源 SHA 错误、相同/不同域、真实任务拒绝合成资料 |
| S2 路径位置和双侧一致性 Evidence Contract | K/R/P/A/C Requirement；明确对象/域/字段/用途/版本/观察窗/来源优先；每个相邻对端独立 P | 双侧缺证、错/未知版本、方向、半开窗接触、配置及映射版本错、端点冲突 |
| S3 专职角色、能力与受限取证 | Capability 表 + QueryPlan；单对象子任务适配旧工具；共享总预算；每绑定记录角色和回执 | 多对象拆分、权限不足、字段能力缺口、无来源、预算停止、跨任务拒绝 |
| S4 多源采信与 K/R/P 条件向量 | source/object/time/version/purpose 过滤；声明来源优先；冲突保留；K/R/P + 独立权限 A；路径条件向量 | 0/false、过期/缺时区/缺身份、历史并存、无优先规则冲突、窗口不可归一 |
| S5 定向补证、局部状态更新 | GapRouter；`compile_gap_plan`；读取依赖四类边；可达失效和直接读者重算；完整判定依据变化传播 | 缺失侧定向、实际值变但状态码相同、无关字段、新增/删除/空值、时间失效、缺边/环/局部预算 |
| S6 影响范围和动作可行性 | ActionTemplate、传播/截断关系、多个半开子区间和路径外 prerequisite；Gate 读取全部必要状态、批次、依据与实际谓词 | 合法正例、值谓词失败、授权变化、旧依据、pending、路径外对象、离线 GateOff 对照 |

本轮实例能力是只读文件/检索/日志读取和离线结构化观测。真实跨域采集、受控执行、动态硬件权限服务与现网业务映射另需实际平台验证。本轮角色为确定性能力与职责分配，没有引入多个自治 LLM 来凭生成内容满足证据要求。
