# P0 评测协议（2026-09-25）

## 评测对象与诚实边界

`slots.jsonl` 包含 120 个**待人工填充和复核的标注名额**，每类数量按迁移计划分配。当前 `question=null`、`gold_evidence_ids=[]`、`label_status=pending_human_review`，它不是 120 条已经有真值的测试题，也不能用于报告准确率。

| 类别 | 数量 | 应标注的关键字段 |
|---|---:|---|
| 命令/参数 | 40 | 产品、命令族、完整原文语法、必选参数、适用版本、出处 |
| 产品知识 | 20 | 产品/网元域、关键事实、出处、版本 |
| 手册排障 | 20 | 症状、检查步骤、操作前提、出处 |
| 日志证据 | 20 | 文件哈希、行号/时间、事件状态、允许的结论 |
| 拓扑 | 10 | 明确合成或真实、源行、设备/接口关系、时效 |
| 缺失/冲突 | 10 | 预期缺口、应追问字段、不能生成的结论 |

总计 120，提议开发/保留测试各 60。`proposed_*` 是容量占位，尚未冻结。完成标注后，应按命令族、手册章节和日志模板/时间区段分组，保证近似问题不跨组泄漏，再把 split 改为 `dev`/`heldout`。保留测试集必须在模型、规则与检索参数定版之后使用一次；若按其失败项调参，应重新留一份独立测试集。

## 标注流程

1. 人工从四份手册和已登记日志选择问题，保留语义原文、资料哈希及页内块/日志行号。论文只能提供问题线索，不能代替原手册或日志证据。
2. 两次独立核对命令字符串、版本与设备范围；不能从相似接口 N6/N7 推导命令。OCR 文字需对原图核对，未核对者不进命令 gold。
3. 每题填写 `question`、`gold_evidence_ids`、`gold_facts`、`forbidden_claims`、`source_group`、`label_status=reviewed`。标记“此资料无答案”时 `gold_evidence_ids=[]` 且有明确缺口。
4. 不具备真实拓扑的题全部标记 `synthetic=true`，真实现场准确率不统计这些题。
5. 评估输出逐题记录检索候选、生成回答、引用、工具路径和资源开销；人工复核 false positive、缺证据拒答、版本混答和日志状态误判。

## 指标

- 检索：Recall@20 与 Hit@20 分开，nDCG@8、精确命令 Top3 命中。
- 回答：关键语法/参数正确率、事实证据支持率、证据不足正确说明率、引用可解析率。
- 日志：行归属率、事件类型/状态混淆矩阵；无根因真值时不报根因准确率。
- Agent：有效补查率、工具参数正确率、预算内结束率、任务恢复与会话隔离。
- 效率：相同样本的首输出、总时延、token 数、调用数、峰值显存/RSS。

固定检索条件比较 dense → dense+BM25/精确 → 加 reranker；固定工具比较固定流程 → 有限 Agent；固定证据和预算比较生成模型。不得同时替换多个环节后把收益归因于某一个模型。

## 工具边界用例清单

每个用例有明确输入与预期状态，后续代码阶段按此表展开至少 100 个参数契约测试。边界集与 120 题业务集分开。

| 用例族 | 必测情形 | 预期 |
|---|---|---|
| 时间 | 无时区、跨日、小数秒、起止倒置、单秒、空窗口 | 显式时区/错误或空数据状态，不漏日尾 |
| 日志 | 正常心跳、告警发生/解除、多行、无时间、逆序、重复、脱敏实体 | 行可回查，状态不混淆，masked 不关联成真实会话 |
| 拓扑 | 缺文件、未知设备、N3/N30、重复边、版本时效冲突、列顺序变化 | 匹配字段而非整行子串，缺口可解释 |
| 手册 | 未知版本、跨网元同名词、合并表格、文本框、OCR O/0、缺命令 | 证据定位正确，未核对 OCR 不作为权威 |
| 工具 | null/错类型/越界参数、未授权工具、模型空输出、超时 | 类型化错误，不执行无效动作 |
| 会话 | 相同请求恢复、不同任务同设备、预算耗尽、重复调用 | 状态隔离，恢复不重复副作用 |
